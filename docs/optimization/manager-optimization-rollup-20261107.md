本批收口此前已开发并本地试用的通用协作优化。源码整合、离线测试、安装、Manager 加载、自然任务采用和收益分别记录；合并不代表两轮真实观察已经完成。

| 优化 | 问题与改动 | 保留边界 |
| --- | --- | --- |
| Manager 通用操作入口 | 将入队、收取正式提交、记录审查决定的机械参数处理交给既有确定性程序与固定宿主模板 | receive 仅进入审查；独立验收后才单独 decision；权限、CAS、幂等及原模式不变 |
| Manager 角色召回 | 已确立 Manager 职责优先；召回投影保留 sharedRules、roleDuties、managerGuidance | 既有单次读取，不增加 Worker/Liaison 读取、字段或启动恢复步骤 |
| 监督规则分层 | 正常监督读取短核心；陌生宿主、参数和异常问题按需查参考 | 结果优先、精确任务摘要；不得因 unknown 或活动陈旧就读取执行正文 |
| 原生状态过滤 | 按状态区分 activeFlags，保留 notLoaded/systemError 等原义及精确身份和完整游标 | 原生完成不等于提交或批准；不能把过滤用于角色召回 |
| notLoaded 按需加载 | 已核实同本地宿主、绑定身份与授权后，只打开原会话一次并复核一次 | 非 idle、身份/轮次冲突、能力未知则保持等待；不发送消息唤醒、不重试循环、不增加 Worker 步骤 |
| 就绪终态兼容 | 支持与精确 idle 观察一致的 completed/interrupted/failed 终态 wake | 只确认宿主空闲，保留业务状态、任务占用与准入保护 |
| 新旧 Manager 入口统一 | 共享路由、完成通知说明和监督核心统一指向 runManagerReviewStage 的 receive/decision | 正常收取不手写事件再 apply；未知或部分生效不自动回退旧写路径，原操作恢复仍兼容 |
