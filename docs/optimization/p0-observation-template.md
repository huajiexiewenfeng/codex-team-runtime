# P0 自然任务观察表

每轮只检验一个假设。由分析者使用已授权、精确任务和时间范围的既有 timeline、metrics 与日志填写，保留来源定位和必要计数。不增加 Worker 标记、调用、汇报或采集服务。缺失/无法归属写 `unknown`，不填 0；不复制执行对话、密钥或隐藏推理。

| 记录项 | 每个自然任务 / attempt 填写 |
| --- | --- |
| 身份与版本 | team、task、attempt、角色、时间窗口；源码与安装哈希；解析器、分类版本；实际加载和实际采用各自的证据及时间（磁盘一致不能证明加载） |
| 完整交付 | 起止事件、来源、结果；中断、失败、返工保留；提交→审查、审查→决定、执行、用户等待与未知间隔分别标注可归因证据 |
| 使用成本 | 按角色及既有 trigger 记录调用和 usage，cached/uncached input、output 分列；未知归属单列，不均摊 |
| 实际读取集合 | 列出实际读取的核心、参考、固定模板等路径，注明触发；记录普通正文读取、诊断理由、召回正文是否保留、固定模板是否采用 |
| 人与质量 | 催问、转发、纠偏；漏报、错投、重复派发、跳过审查、返工及原因；各附事件引用 |
| 反例与去留 | 假设、反例、覆盖缺口、体验、可比数据；建议保留、收窄、修正、继续观察或回退 |

同一时钟口径内比较，声明与观测时间不直接相减，重叠区间不相加，未知间隔不归咎 Runtime。字节不换算 Token，优化会话成本单列。两轮自然完整任务仅用于初筛；两周为人工回看节点。只有同类完整任务有可靠同口径基线才算总 Token 增幅（初始观察上限 30%，超出交用户判断）。缺样本的团队标 unknown。
