# 团队工作台：一个入口，两种证据

`dashboard-serve` 默认提供「任务进度 / 指标统计」两个页签。任务、成员与验收
来自状态台账和 Registry；指标来自显式绑定的团队日报，不混用刷新时间。

```text
node src/cli.mjs dashboard-serve <state.json> --port 0 --metrics-report <report.json>
```

`report.json` 必须是本团队 `metrics-daily-export` 的输出，不接受旧 Token 单页
或任意 HTML。未绑定时指标页显示未接入；非法文件、其他团队报告、超过 16 MiB
的文件拒绝展示，不返回私有路径。报告仍保留数据截至时间、日期窗口、时区、
来源和缺失信息。当前成员与日报有用量记录的成员进行对照，不声称覆盖完整。

任务页可见且未暂停时每 5 秒检查记录。切换到指标页、隐藏或关闭页面后停止
任务请求。指标页在选中或点击「重新读取报告」时读取指定文件，不扫描日志、
不采集或生成统计、不唤醒 Agent。更新统计仍使用已授权的导入和导出流程。

界面只保留一个品牌页头；同步工具栏压缩为紧凑区域；任务汇总前置，轮次历时
默认折叠，窄屏导航变为横排。指标保留 Token/MCP 内层页签，样式隔离于任务页。
只读接口、凭据、Host/Origin 检查及 CSP 保持有效，不提供文件浏览或写入接口。

旧服务不会热更新页面代码。升级运行目录后，由操作者核对并替换**对应看板服务**；
无需为这项页面改动重启 Codex。不要结束其他团队的 Node 进程。

## 本轮验证范围

使用模拟团队和临时日报进行受控验证，不修改真实团队状态或旧指标报告。
服务/API、报告身份与格式、页签键盘交互、自动请求边界均由相关测试覆盖。
2026-09-13 的内嵌浏览器模拟验收确认：桌面首屏无重复品牌页头；任务汇总前置；
Token/MCP 切换与方向键切换正常；切到指标页后读取计数保持 6 不再增加。
窄屏目标 375px（有效文档宽 360px）中，文档 scrollWidth 与 clientWidth 均为 360，
未发生整页横向溢出；浏览器错误日志为空。空成员行不算已观测成员。
这些是模拟测试结果，不代表真实团队已升级安装或指标覆盖完整。
