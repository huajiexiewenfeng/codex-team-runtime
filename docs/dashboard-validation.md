保留设计时的详细核对清单，不能将用户概括确认伪装成每个组合均有测量记录：

1. 1440 / 1024 / 768 / 375 CSS px 与横屏无水平溢出，长标题、长证据和身份字段可阅读。
2. 六类 radio 筛选对应正确任务，空分类有提示；鼠标与键盘可操作。
3. details 可展开 / 收起；Tab 焦点清晰、不被遮挡；文字缩放与 reduced-motion 可用。
4. 成员锚点能定位被当前分类隐藏的任务，保留显示的说明准确；切换历史和浏览器返回不误导范围。
5. 验证兼容入口是否被浏览器接受、是否打开正确测试线程并核对主机身份；不发送消息、不重启任务。当前默认仍禁用，只有显式 opt-in 的验收包包含 URI。准确 host/thread 导航的缺口不能由兼容入口或静态源码检查代替。
